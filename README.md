# AmbitionForge

**Forge Your Ambition. Shape Your Future.**

A student-led community helping students turn ambition into action through skills, opportunities, mentorship, technology, and leadership.

---

## 📌 About

AmbitionForge is a premium student community platform built with vanilla HTML, CSS, and JavaScript. It provides a clean, minimal, and responsive interface for students to discover opportunities, learn new skills, connect with peers, and grow their careers.

---

## 🚀 Features

### Core Pages
- **Home** (`index.html`) - Hero section, stats, about preview, events preview, FAQ
- **About** (`about.html`) - Mission, vision, values, focus areas, founder
- **Ambassador Hub** (`ambassador.html`) - Student ambassador programs, roadmap, tips
- **Community** (`community.html`) - WhatsApp groups, values, member highlights
- **Events** (`events.html`) - Upcoming and past events with posters

### Design Features
- 🌙 **Dark Mode (Default)** - Premium dark theme with light mode toggle
- 📱 **Fully Responsive** - Works on 320px to 1920px screens
- 🎨 **Google-Inspired Colors** - Blue, Red, Yellow, Green accents
- ✨ **Premium Animations** - Smooth transitions, hover effects, scroll reveals
- 🎯 **Minimal Design** - Clean whitespace, rounded cards, subtle shadows

### Functionality
- 🔍 **Event System** - Add events easily via `events-data.js`
- 📋 **Copy to Clipboard** - Email and GID copy with mobile fallback
- 💾 **LocalStorage** - Theme preference, saved data
- 🔔 **Toast Notifications** - Success/error messages
- 🖼️ **Poster Fullscreen** - Click event poster to view fullscreen
- 🌗 **Theme Toggle** - Desktop + Mobile toggle buttons
- 📱 **Mobile Navigation** - Hamburger menu with smooth animation
